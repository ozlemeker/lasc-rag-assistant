# Foundry Local RAG Assistant

A Retrieval-Augmented Generation (RAG) application built with Microsoft Foundry Local and Phi-3.5 Mini.

## Features

- PDF document loading
- Document chunking
- Embedding generation
- ChromaDB vector database
- Retrieval pipeline
- Local inference with Phi-3.5 Mini
- Streamlit interface
